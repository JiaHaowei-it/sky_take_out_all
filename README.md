# sky_take_out_all
苍穹外卖完整项目,包含后端代码、web端代码、微信小程序代码、数据库脚本


database中存放的是数据库脚本


front中存放的是前端代码,包含web端代码、小程序端代码


front/前端代码/sky中存放的是web端完整代码


front/前端代码中的nginx-1.20.2是nginx服务器,代码拉取后将此文件夹放至其他位置,在此文件夹中只需双击nginx.exe即可启动nginx服务


sky-server/src/main/resources中的生产环境配置文件已经将隐私数据去除,需要自己将自己的配置数据进行配置
